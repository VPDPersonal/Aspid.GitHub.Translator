Читайте пул-реквесты на своём языке.

Aspid Lingo for GitHub переводит пул-реквесты, код-ревью, коммиты и README прямо на github.com, на том же месте, где был оригинал. Код, ссылки и упоминания остаются как есть, а оригинал всегда в одном клике.

Бесплатно и приватно: перевод выполняет встроенный в Chrome переводчик на вашем устройстве. Без аккаунта, без API-ключей, без серверов.

ЧТО ПЕРЕВОДИТСЯ
• Пул-реквесты: заголовок, описание, обсуждение и комментарии код-ревью
• Коммиты: заголовки и описания в списке коммитов, на странице коммита и в ленте пул-реквеста
• README на главной странице репозитория и в папках, а также любой открытый .md файл

КОД ОСТАЁТСЯ КОДОМ
Блоки кода, inline-код, идентификаторы вроде SerializeReference, @упоминания, ссылки на #issue, ссылки, префиксы conventional commits (fix(scope):) и git-трейлеры (Co-Authored-By:) не переводятся.

ОРИГИНАЛ В ОДНОМ КЛИКЕ
• У каждого комментария свой переключатель «Показать оригинал»
• У заголовков и коммитов оригинал виден при наведении
• Плавающая кнопка переключает всю страницу между переводом и оригиналом

БЫСТРО ДАЖЕ НА ОГРОМНЫХ ПУЛ-РЕКВЕСТАХ
Переводится только то, что появляется на экране, а текст, который уже на вашем языке, пропускается. Новые и отредактированные комментарии и переходы между страницами без перезагрузки подхватываются сами.

ВАШИ ПРАВИЛА
• Перевод на русский, английский, украинский, немецкий, французский, испанский, итальянский, португальский, польский, турецкий, китайский, японский или корейский
• Автоматически или по одному клику
• Отключите коммиты, README или комментарии ревью одной галочкой

КОНФИДЕНЦИАЛЬНОСТЬ
• Текст переводит Chrome на вашем устройстве. У расширения нет серверов, и оно ничего никуда не отправляет.
• Chrome один раз скачивает у Google языковую модель для пары языков. Ваш текст в этот запрос не входит.
• Расширение работает только на github.com и просит одно разрешение, storage, чтобы хранить настройки.
• Никакой аналитики, слежки и аккаунтов.
• Перевод видите только вы. На GitHub ничего не публикуется.

ТРЕБОВАНИЯ
Chrome 138 или новее на компьютере. Когда вы впервые переводите с нового языка, нажмите кнопку 🌐 в правом нижнем углу: Chrome один раз скачает языковую модель.
