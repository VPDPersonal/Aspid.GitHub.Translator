Review pull requests in your own language.

Aspid Lingo for GitHub translates pull requests, code review, commits and READMEs right on github.com, in the place where the original was. Code, links and mentions stay as they are, and the original is always one click away.

Free and private: translation runs on your device with the translator built into Chrome. No account, no API key, no servers.

WHAT GETS TRANSLATED
• Pull requests: the title, description, conversation and code review comments
• Commits: titles and descriptions in the commit list, on the commit page and in the PR timeline
• READMEs on the repository home page and in folders, and any .md file you open

CODE STAYS CODE
Code blocks, inline code, identifiers such as SerializeReference, @mentions, #issue references, links, conventional commit prefixes (fix(scope):) and git trailers (Co-Authored-By:) are never translated.

THE ORIGINAL IS ONE CLICK AWAY
• Every comment has its own "Show original" toggle
• Titles and commits show the original on hover
• A floating button flips the whole page between the translation and the original

FAST ON HUGE PULL REQUESTS
Only what scrolls into view gets translated, and text that is already in your language is skipped. New and edited comments and page switches without a reload are picked up on their own.

YOUR RULES
• Translate into English, Chinese, French, German, Italian, Japanese, Korean, Polish, Portuguese, Russian, Spanish, Turkish or Ukrainian
• Translate automatically or with one click
• Turn off commits, READMEs or review comments with one checkbox

PRIVACY
• Text is translated by Chrome on your device. The extension has no servers and sends nothing anywhere.
• Chrome downloads a language model from Google once per language pair. Your text is not part of that request.
• The extension runs only on github.com and asks for one permission, storage, to keep your settings.
• No analytics, no tracking, no account.
• Only you see the translation. Nothing is posted to GitHub.

REQUIREMENTS
Desktop Chrome 138 or newer. The first time you translate a language pair, click the 🌐 button in the bottom right corner: Chrome downloads the language model once.
